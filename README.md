# 글감 찾기 — 서버 개설 안내

학생 20명이 이틀 쓰는 수업용입니다. 터미널 없이 브라우저만으로 끝납니다.
전체 40분쯤 걸리고, 비용은 **API 2천 원 안쪽 + 호스팅 무료**입니다.

---

## 먼저 알아 둘 것

**키가 없거나 서버가 멈춰도 수업은 돌아갑니다.** 학생 화면은 AI가 응답하지 않으면
자동으로 '안내 모드'로 내려가 미리 준비된 질문으로 끝까지 진행됩니다.
그러니 아래 과정이 잘 안 풀려도 수업은 하실 수 있습니다.

---

## 1단계 · API 키 받기 (15분)

1. **platform.claude.com** 에 접속해 계정을 만듭니다. 평소 쓰시는 Claude 계정과 별개입니다.
2. 왼쪽 메뉴에서 **Billing**(결제)으로 들어가 카드를 등록하고 **크레딧을 충전**합니다.
   - **5달러면 이 수업에 충분하고도 남습니다.** 자세한 계산은 아래 '비용' 항목에 있습니다.
   - 크레딧 방식이라 등록한 카드에서 매달 빠져나가지 않습니다.
3. **Settings → API keys** 로 들어가 **Create key** 를 누릅니다.
   - 이름은 아무거나 (예: `국어수업`)
   - 만들면 `sk-ant-` 로 시작하는 긴 문자열이 **딱 한 번만** 보입니다.
4. **이 키를 메모장에 복사해 두세요.** 창을 닫으면 다시 볼 수 없고, 새로 만들어야 합니다.

> 키는 비밀번호와 같습니다. 학생에게 보여주거나 메신저로 보내지 마세요.
> 이 도구는 키를 서버에만 두고 학생 화면으로는 내보내지 않습니다.

---

## 2단계 · 파일 올리기 (10분)

GitHub에 파일을 두고, Vercel이 그걸 가져가 서비스하는 구조입니다. 둘 다 무료입니다.

1. **github.com** 에서 계정을 만듭니다.
2. 오른쪽 위 **+ → New repository** 를 누릅니다.
   - 이름: `geulgam`
   - **Public** 으로 둡니다 (키는 여기 들어가지 않으니 괜찮습니다)
   - **Create repository**
3. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 받으신 폴더 안의 파일을 **폴더 구조 그대로** 끌어다 놓습니다.
   화면에 아래처럼 보여야 합니다.

```
api/ask.js
api/check.js
public/index.html
package.json
vercel.json
```

5. 아래 **Commit changes** 를 누릅니다.

> 끌어다 놓을 때 `api` 와 `public` 폴더째로 올리셔야 합니다.
> 파일만 따로 올리면 경로가 달라져 작동하지 않습니다.

---

## 3단계 · 서비스 띄우기 (10분)

1. **vercel.com** 에 접속해 **Continue with GitHub** 으로 가입합니다.
2. **Add New → Project** 를 누르고 방금 만든 `geulgam` 을 **Import** 합니다.
3. 설정 화면에서 **Environment Variables**(환경 변수)를 펼칩니다.
   - Name: `ANTHROPIC_API_KEY`
   - Value: 1단계에서 복사해 둔 `sk-ant-...` 키
   - **Add** 를 누릅니다
4. **Deploy** 를 누르고 1~2분 기다립니다.
5. 끝나면 `https://geulgam-....vercel.app` 같은 **주소가 나옵니다.**
   **이 주소가 학생들이 들어올 주소입니다.**

---

## 4단계 · 확인 (5분)

### 먼저 점검 화면부터

주소 뒤에 **`/api/check`** 를 붙여서 열어 보세요.

```
https://내주소.vercel.app/api/check
```

무엇이 되고 무엇이 안 되는지 한국어로 알려 줍니다.
**"모두 정상입니다"** 가 떠야 다음으로 넘어갑니다.
안 되면 그 화면이 무엇을 고쳐야 하는지 바로 일러 줍니다.

> 가장 흔한 원인은 **환경 변수를 넣고 다시 배포하지 않은 것**입니다.
> Vercel은 환경 변수를 바꾼 뒤 **Deployments → 맨 위 항목 → ⋯ → Redeploy** 를 눌러야 반영합니다.

### 그다음 학생 화면으로

주소를 열어 실제로 한 바퀴 돌려 보세요.

- [ ] 오른쪽 위에 **`AI 함께`** 라고 떠 있는가
      (`안내 모드` 라고 뜨면 키가 안 들어간 것입니다. 3단계 환경 변수를 다시 보세요)
- [ ] 글감 질문에 답했을 때, 내가 쓴 말을 짚는 질문이 돌아오는가
- [ ] 휴대폰으로도 열어 보기 (학생은 태블릿으로 봅니다)
- [ ] 초고 단계에서 `막혔어요` 를 눌러 보기
- [ ] 다듬기 단계에서 **AI가 고쳐 쓴 문장을 주지 않는지** 확인

> 환경 변수를 나중에 바꾸셨다면 **Deployments → 맨 위 항목 → ⋯ → Redeploy** 를 눌러야 반영됩니다.

## 비용

| 항목 | 금액 |
| --- | --- |
| 학생 1명이 한 차시에 쓰는 양 | 약 20원 |
| 20명 × 2차시 | **약 700원** |
| 테스트와 여유분까지 | **1,500원 안쪽** |
| Vercel 호스팅 | 무료 |

5달러를 충전하시면 같은 수업을 여러 반, 여러 학기에 걸쳐 쓰실 수 있습니다.
Console의 **Usage** 메뉴에서 실제로 얼마나 썼는지 언제든 확인하실 수 있습니다.

비용이 갑자기 늘지 않도록 두 가지를 걸어 두었습니다.

- 한 기기가 한 시간에 **80번까지만** 부를 수 있습니다
- 가장 저렴한 모델(Haiku)을 쓰고, 한 번에 받는 답의 길이도 제한했습니다

더 안전하게 하시려면 Console의 **Billing → Usage limits** 에서 월 상한을 걸어 두세요.

## 수업이 끝난 뒤

- **그대로 두셔도 됩니다.** 학생이 안 쓰면 비용이 들지 않습니다.
- 당분간 안 쓰실 거면 Vercel 프로젝트 설정에서 **Pause** 해 두셔도 됩니다.
- 키를 더 안 쓰실 거면 Console의 **Settings → API keys** 에서 지우시면 됩니다.

## 파일이 하는 일

| 파일 | 하는 일 |
| --- | --- |
| `public/index.html` | 학생이 보는 화면 전부. 글감 모으기부터 완성까지 |
| `api/ask.js` | 학생 질문을 Claude에게 대신 묻는 중계. 키는 여기에만 있습니다 |
| `api/check.js` | 선생님용 점검 화면. `/api/check` 로 열면 상태를 알려 줍니다 |
| `package.json`, `vercel.json` | Vercel이 읽는 설정 |

학생이 쓴 글은 **그 학생 기기에만** 저장되고 서버로 넘어오지 않습니다.
서버는 질문을 중계만 하고 아무것도 보관하지 않습니다.
